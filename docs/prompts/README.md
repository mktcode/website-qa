# Promptvorlagen

Dieses Verzeichnis enthält wiederverwendbare Arbeitsaufträge für Website-Prüfungen. Die fachlich maßgebliche Grundlage liegt unter [`../checklisten/`](../checklisten/).

Eine Promptvorlage ersetzt weder die zugrunde liegende Checkliste noch eine ausgefüllte Projektakte. Projektspezifische Ergebnisse, Freigaben und Nachweise gehören ausschließlich in das jeweilige Website-Repository oder dessen operative Akte.

- [`website-checkliste.md`](website-checkliste.md) – Bestandsanalyse, Zusammenstellung der modularen Website-Vorlage, kontrollierte Umsetzung und Produktionsverifikation.

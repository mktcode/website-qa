# Dokumentation

Dieses Verzeichnis enthält allgemeine, wiederverwendbare Unterlagen für Website-Qualitätssicherung. Es enthält keine ausgefüllten Projektakten und keine Nachweise für eine konkrete Website.

## Inhalte

- [`checklisten/website/`](checklisten/website/) – modulare Ausgangsvorlage mit verpflichtendem Kern, bedingten Fachmodulen und wiederholbaren Prüfverfahren.
- [`prompts/website-checkliste.md`](prompts/website-checkliste.md) – wiederverwendbarer Arbeitsauftrag zur kontrollierten Anwendung der modularen Vorlage.

## Verwendung

Vor einer Prüfung werden Vorlagenstand und Quellcommit festgehalten. Aus der Vorlage entsteht im jeweiligen Website-Repository eine eigenständige Projektkopie. Nur diese Projektkopie darf mit Status, Projektdaten, Nachweisen und akzeptierten Abweichungen ausgefüllt werden.

Änderungen an diesen allgemeinen Vorlagen setzen bestehende Projektpunkte niemals automatisch auf erledigt. Vorlagendeltas werden kontrolliert bewertet und in der jeweiligen Projektakte dokumentiert.

Die technischen CLI-Prüfer erzeugen begrenzte Teilnachweise. Sie ersetzen weder fachliche Bewertung noch manuelle, rechtliche, organisatorische oder plattformspezifische Prüfungen.

# Dokumentation

Dieses Verzeichnis enthält allgemeine, wiederverwendbare Unterlagen für Website-Qualitätssicherung. Es enthält keine ausgefüllten Projektakten und keine Nachweise für eine konkrete Website.

## Inhalte

- [`checklisten/website/`](checklisten/website/) – zentrale modulare Checkliste mit verpflichtendem Kern, bedingten Fachmodulen und wiederholbaren Prüfverfahren.
- [`compatibility.md`](compatibility.md) – aktueller technischer v2-Vertrag.

## Verwendung

Vor einer Prüfung werden Vorlagenstand und Quellcommit festgehalten. Aus der Vorlage entsteht im jeweiligen Website-Repository eine eigenständige Projektkopie. Nur diese Projektkopie wird durch Menschen mit Status, Projektdaten und Nachweisen bearbeitet.

Änderungen an der Vorlage und technische Signale setzen bestehende Projektpunkte niemals automatisch auf erledigt. Die fünf CLI-Prüfer liefern lediglich statische, begrenzte Beobachtungen als erste Standortbestimmung.
